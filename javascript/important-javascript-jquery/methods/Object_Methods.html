Object Methods

https://www.w3schools.com/jsref/jsref_obj_object.asp
  1. constructor Returns the function that created an object's prototype
  2. keys() Returns an Array Iterator object with the keys of an object
  3. prototype Let you to add properties and methods to JavaScript objects
  4. toString() Converts an object to a string and returns the result
  5. valueOf() Returns the primitive value of an object

        
    const car = { make: "Tesla", model: "Model 3", year: 2024 };
    console.log(car);
    console.log(Object.keys(car)); // ['make', 'model', 'year']
    console.log(Object.values(car)); // ['Tesla', 'Model 3', 2024]
    console.log(Object.entries(car)); // [ ['make', 'Tesla'], ['model', 'Model 3'], ['year', 2024] ]

    const specs = { battery: "Long Range", drive: "AWD" };
    // Merges 'car' and 'specs' into a brand new empty object
    const fullCarInfo = Object.assign({}, car, specs);
    console.log(fullCarInfo); // { make: "Tesla", model: "Model 3", year: 2024, battery: "Long Range", drive: "AWD" }

    const fullCarInfo1 = Object.assign(car, specs);
    console.log(fullCarInfo1); // { make: "Tesla", model: "Model 3", year: 2024, battery: "Long Range", drive: "AWD" }

    console.log(car); // { make: "Tesla", model: "Model 3", year: 2024, battery: "Long Range", drive: "AWD" }
